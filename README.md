# Tienda Virtual de Ropa - Sistemas Distribuidos

Estructura base del proyecto (Primer Parcial).

## Estructura
- server/: Backend con Node.js, Express y WebSockets.
- client/: Frontend con React y Vite.

## Instrucciones para el equipo
1. Descargar cambios:
   git pull origin main
   git checkout -b feature/tu-modulo

2. Iniciar Backend:
   cd server && npm install && node index.js

3. Iniciar Frontend:
   cd client && npm install && npm run dev
